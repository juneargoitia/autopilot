## 1. Introducción y objetivos del trabajo

### Introducción
En esta práctica se desarrollará un sistema simplificado de seguimiento de carril utilizando Python y la biblioteca OpenCV. El sistema analizará una grabación de vídeo realizada desde un vehículo en movimiento y deberá identificar y seguir las marcas viales que delimitan la parte derecha del carril. 

El objetivo principal no es implementar un sistema completo de conducción autónoma, sino desarrollar algunos de los mecanismos básicos de percepción visual utilizados en este tipo de aplicaciones para interpretar el entorno a partir de imágenes de la cámara del vehículo.

### Objetivos
Los principales objetivos de la práctica son los siguientes:
- Familiarizarse con el procesamiento de secuencias de vídeo utilizando OpenCV.
- Aplicar técnicas de preprocesamiento, filtrado de imágenes y selección de regiones de interés (ROI).
- Utilizar algoritmos de detección de bordes, como el operador de Canny.
- Aplicar técnicas de detección de líneas mediante la transformada de Hough.
- Desarrollar estrategias para localizar y seguir marcas viales, analizando su evolución temporal.
- Resolver situaciones progresivamente más complejas, tales como tramos rectos, curvas suaves y pronunciadas, zonas de sombra, transiciones entre marcas continuas y discontinuas, y cambios de carril o salidas de la vía.

### Material proporcionado
El sistema trabajará con una grabación de vídeo obtenida desde una cámara situada en la parte delantera del vehículo, la cual presenta diversos retos y grados de dificultad a lo largo del recorrido (curvas, sombras, líneas discontinuas y salidas).
